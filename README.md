# Subra Products API Docs

Това repo съдържа клиентския пакет за интеграция с публичното продуктово API на Subra.

## Файлове

- `Subra-Products-API-README.md`
- `Subra-Products-API.postman_collection.json`
- `Subra-Products-API.postman_environment.json`

## Бърз старт

1. Импортирайте collection файла в Postman.
2. Импортирайте environment файла.
3. Изберете `Subra API Environment`.
4. Попълнете `catalog_token` и `main_api_token`.

Основната документация е в `Subra-Products-API-README.md`.
